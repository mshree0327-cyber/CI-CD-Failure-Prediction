CI/CD Failure Prediction

A leakage-aware dashboard for pre-build risk prediction, model evaluation and SHAP-based explanations.

Pre-build data only: Enter information available before the current build starts. Do not enter build duration, test results, current build status, or other execution outcomes.

How to use

A simple pre-build workflow

  1. Provide the repository and code-change features available before a build starts.
  2. Run the prediction and review the failure and success probabilities.
  3. Use SHAP factors and recommendations to understand the prediction, then consult evaluation results for model performance context.

    Receiver Operating Characteristic (ROC) curve

    Shows the trade-off between failure recall (true positive rate) and false positive rate across probability thresholds.

    Precision–Recall curve

    Shows failure precision versus failure recall across thresholds. The dashed reference line represents failure prevalence in the held-out test set.

    ROC-AUC measures ranking discrimination. Average Precision summarizes the precision–recall curve. Neither selects an operating threshold by itself.
