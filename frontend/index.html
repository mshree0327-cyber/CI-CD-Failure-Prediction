Receiver Operating Characteristic (ROC) curve

Shows the trade-off between failure recall (true positive rate) and false positive rate across probability thresholds.

Precision–Recall curve

Shows failure precision versus failure recall across thresholds. The dashed reference line represents failure prevalence in the held-out test set.

ROC-AUC measures ranking discrimination. Average Precision summarizes the precision–recall curve. Neither selects an operating threshold by itself.
